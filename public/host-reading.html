📖 Cómo se usa
  1. Espera a que tus alumnos se unan con el PIN.
  2. Pulsa Abrir libro — todos verán la primera página.
  3. Pulsa ▶ Reproducir para iniciar el audio y la lectura sincronizada.
  4. Cada palabra se ilumina cuando el narrador la dice. Solo pinyin — sin caracteres chinos.
  5. ← Atrás / Siguiente → cambian la página para todos.
  6. Si pausas, los teléfonos también pausan al instante.
