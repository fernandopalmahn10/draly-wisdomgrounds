# 🎭 Character Prompt Pack — 20 characters × 3 prompts each

Each character needs **3 generations**:
- **A** = idle / walking-in pose (🍌 Nano Banana, FREE)
- **B** = signature action pose (🍌 Nano Banana, FREE)
- **V** = 5-second victory animation (🎬 Higgsfield video, ~$3 each)

Total cost: **~$60** for all 20 characters (assuming you do all videos).
If you skip some V's, even cheaper. Each character can debut with just A+B (free) and add video later.

**Global rule for ALL prompts**: chibi 3D Pixar-style proportions, big head small body, big sparkly friendly eyes, kid-friendly NOT scary, transparent background PNG with alpha channel for A and B, OR chroma-key green #00FF00 if alpha unavailable. **Negative**: scary, violent, realistic photo, watermark, text overlay, deformed faces, adult content.

**Save paths**: every file goes to `public/assets/cutscenes/chars/<id>-{a,b,victory}.{png,mp4}` where `<id>` matches the character key. The platform auto-finds them.
